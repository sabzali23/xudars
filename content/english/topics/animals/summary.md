# Животные и слова по картинкам

На экзамене есть задания, где нужно **узнать слово по картинке** и **вставить пропущенные буквы**. Слова там простые и повторяются из года в год — в основном животные и знакомые предметы. Их достаточно выучить.

## 1. Слова, которые нужно знать

| Картинка | По-английски | Как звучит |
|---|---|---|
| кошка | cat | кэт |
| собака | dog | дог |
| лошадь | horse | хос |
| мышь | mouse | маус |
| кролик | rabbit | рэбит |
| медведь | bear | бэа |
| змея | snake | снэйк |
| попугай | parrot | пэрот |
| кенгуру | kangaroo | кэнгару |
| велосипед | bicycle | байсикл |

Колонка «как звучит» — для взрослого, чтобы прочитать вслух. Ребёнку показывать её не нужно.

## 2. Слова-ловушки

Именно на них теряют баллы: слова отличаются одной-двумя буквами, а значат совсем разное.

- **rabbit** (кролик) — **carrot** (морковка) — **parrot** (попугай)
- **mouse** (мышь) — **house** (дом)
- **snake** (змея) — **snack** (перекус)
- **bear** (медведь) — **bird** (птица)

Когда в задании под картинкой три подписи, обычно две из них — как раз такие ловушки.

## 3. Как вставлять пропущенные буквы

В задании даётся слово с дырками: **H__RS__**, **R__BB__T**, **CA__**.

Порядок действий:
1. Посмотреть на картинку и сказать слово вслух по-русски, потом по-английски.
2. Проговорить слово по буквам: H-O-R-S-E.
3. Вписать те буквы, которых не хватает.

Трудные места в написании:

- **rabbit** — две буквы **b** подряд;
- **kangaroo** — две буквы **o** в конце;
- **bicycle** — в середине **c**, в конце **-cle**;
- **horse** — на конце немая **e**, она не читается, но писать её нужно.

## 4. Как учить

Не списком, а по 3–4 слова за раз, с картинками. Лучше всего работает так: показать картинку — назвать слово — написать его по буквам вслух.

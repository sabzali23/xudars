# Порядок и закономерности

На экзамене три задания проверяют одно и то же умение — видеть порядок: расставить картинки по номерам, вписать пропущенный день недели и продолжить ряд предметов.

## 1. Что было сначала, что потом

На листе четыре картинки: дедушка с ребёнком копают ямку, сажают саженец, поливают, собирают яблоки. Нужно расставить 1, 2, 3, 4.

Как рассуждать: **найти самое первое** действие, потом самое последнее, а серединку расставить между ними.

1. Выкопали ямку — без неё сажать некуда.
2. Посадили саженец.
3. Полили.
4. Выросли яблоки — это точно в конце, ждать дольше всего.

Тот же приём работает с любой историей: сначала причина, потом результат.

## 2. Дни недели

Их семь, и они всегда идут в одном порядке:

| По-русски | По-английски |
|---|---|
| понедельник | Monday |
| вторник | Tuesday |
| среда | Wednesday |
| четверг | Thursday |
| пятница | Friday |
| суббота | Saturday |
| воскресенье | Sunday |

В задании один день пропущен — нужно назвать его. Проще всего проговорить весь ряд с начала и услышать, где дырка.

> На экзаменационном листе пропущен **Thursday** (четверг) — между Wednesday и Friday.

## 3. Что дальше: закономерность

В ряду предметы повторяются по очереди: **мяч, машинка, мяч, машинка, …** Дальше снова **мяч**.

Как найти правило:
1. Посмотреть на первые два-три предмета.
2. Спросить себя: что повторяется?
3. Продолжить это повторение.

Закономерности бывают разные:

- чередование: круг, квадрат, круг, квадрат…
- цвета: красный, синий, красный, синий…
- числа по порядку: 1, 2, 3, 4…
- числа через одно: 2, 4, 6, 8…

## 4. Главная подсказка

Во всех этих заданиях ответ не нужно придумывать — его нужно **увидеть в самом ряду**. Если правило найдено, ответ получается сам.
